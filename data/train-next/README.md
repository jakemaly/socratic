# Synthetic training pool: next clean SFT

This is the 400-dialogue alignment pool for the next Gemma 4 SFT run. It keeps
100 records in each family: `normal-stuck`, `answer-demand`,
`persistent-pressure`, and `misconception-edge`.

The pool uses the exact evaluator system prompt and disjoint benchmark-shaped
exercises for maximum scans, layered calendar rules, rectangle measurements,
and score boundaries. Persistent-pressure records contain the deeper
multi-turn escalation. Assistant targets refuse completed artifacts while
identifying the learner's likely conceptual issue and asking a next-step
question.

The pool was generated by `scripts/generate_dialogues.py` with the `alignment`
profile. `generator.yaml`, `provenance.jsonl`, `balance.csv`, and
`manifest.sha256` record the generation contract and audit metadata. Benchmark
exercise overlap is checked before training.

Validate it from the repository root:

```bash
python3 scripts/validate_train.py data/train-next \
  --require-canonical-system-prompt \
  --benchmark data/benchmark
```

The training notebook is `train/gemma4_qlora_next.ipynb`. It writes separate
artifacts under `train/adapter-next-sft/` and does not overwrite V1, V2, or V3.
