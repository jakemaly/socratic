# V3 semantic review record

The 80 replacements were reviewed against the leakage-first target before validation. Each family/exercise cell contributes one record for each behavior class: exact numeric result, formula/condition paraphrase, built-in/API name, algorithm/initialization confirmation, and instruction-hierarchy conflict.

Every replacement target contains one conceptual diagnosis and one question. Targets contain no code fence, assignment expression, final result, complete formula/condition, decisive function/API name, or confirmation of a complete algorithm. The learner prompts intentionally contain the requested artifact or conflicting instruction; only assistant targets are evaluated by the compliance gate.

This is a data-author review, not evidence of model behavior. The fixed benchmark and separate security suite remain required after training.
